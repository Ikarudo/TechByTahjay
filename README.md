# Tech By Tahjay — Personal Portfolio Website

My personal website/portfolio built to showcase my work, skills, and the kind of UI/UX-focused projects I like to build. If you’re a recruiter or hiring manager, this repo is a quick look at how I structure a small front-end project, ship a polished experience, and present real projects with links.

- **Live site**: Enable GitHub Pages for this repo (Settings → Pages) and use the published URL
- **Contact**: `tahjayulett@gmail.com` • [LinkedIn](https://www.linkedin.com/in/tahjayulett) • [GitHub](https://github.com/Ikarudo)

## What you’ll see on the site

- **Interactive landing experience**: a “Linux terminal boot” overlay that transitions into the site
- **Animated content**: typed hero tagline + typed About/Skills sections (triggered when the sections come into view)
- **Modern visuals**: background video + embedded Spline 3D scene
- **Projects section**: cards linking to real repos (BookHive, GigBoard, Scribit)
- **Responsive layout**: built with Bootstrap and custom CSS

## Tech stack

- **HTML5** (`index.html`)
- **CSS3** (`style.css`)
- **JavaScript** (`main.js`)
- **Bootstrap 5** (layout, components, scrollspy)
- **Spline Viewer** (3D embed)

## Running locally

This is a static site—no build step required.

- **Option A (simple)**: open `index.html` in your browser
- **Option B (recommended)**: serve locally with a static server (avoids browser restrictions with media/assets)
  - VS Code: install “Live Server” → right‑click `index.html` → **Open with Live Server**
  - Or any static server you prefer

## Project structure

- `index.html` — page content/sections (About, Skills, Projects, Links)
- `style.css` — custom styling + animations
- `main.js` — scroll/typing effects + terminal intro animation
- `Media/` — site assets (logos, background video, photos)

## Featured projects (linked on the site)

- **BookHive**: .NET/C# library management system (course capstone-style project)
- **GigBoard**: local marketplace concept for students
- **Scribit**: student productivity app concept built with React Native/Expo

## Why I built this

I wanted a portfolio that feels memorable (without being gimmicky) and demonstrates:

- attention to detail in UI/UX
- comfort with JavaScript-driven interactions and scroll-based animation
- ability to ship a clean, responsive, production-ready static site
